# What's That Sound?

**The Ultimate Audio Recognition Game · OASIS Omniverse**

What's That Sound? is an audio recognition game with seven brutal difficulty levels from Wussy to God Like. Identify sounds, fill the recognition ring, and earn OASIS karma. Part of the OASIS Omniverse.

## Difficulty Levels

| Level | Description |
|---|---|
| 🟢 **Wussy** | Clear, obvious everyday sounds |
| 🟡 **Easy** | Common sounds with mild ambiguity |
| 🟠 **Medium** | Sounds that require some thought |
| 🔴 **Hard** | Obscure, heavily layered or processed sounds |
| 🟣 **Expert** | Near-impossible without encyclopaedic audio knowledge |
| ⚫ **Insane** | Sounds you didn't know existed |
| ☠️ **God Like** | Reserved for the truly unhinged |

## Features

- **7 difficulty tiers** — from casual fun to career-ending challenge
- **Recognition ring** — visual fill feedback as confidence builds with each attempt
- **Leaderboards** — global OASIS avatar-linked rankings per difficulty tier
- **Karma rewards** — correct answers earn OASIS karma; harder levels earn more
- **Sound categories** — nature, machines, instruments, animals, urban, abstract, OASIS world
